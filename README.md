# Elective Career Explorer

A responsible AI prototype that helps students explore electives by checking prerequisites, timetable conflicts, career pathways, learning outcomes, and student goals.

## Project Status

🚧 Prototype development in progress.

## Planned Features

- Student profile and career goal
- Prerequisite checking
- Schedule conflict detection
- Career pathway exploration
- Course outcome matching
- Explainable recommendations
- Fallback workflow
- Baseline comparison
- Failure/edge-case testing
- Evaluation metrics
- Responsible AI documentation

- Python

## Data

The project will use synthetic/anonymised educational data for demonstration and evaluation.

## Responsible AI

The system is designed as a decision-support tool. It should explain recommendations and keep the final elective decision with the student and/or academic advisor.
